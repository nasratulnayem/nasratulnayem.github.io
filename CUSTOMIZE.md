# Customize this portfolio

- Update your name, bio, email, avatar, and social links in `_config.yml`.
- Change the header menu in `_data/navigation.yml`.
- Edit service pages in `_pages/` and add new pages there when needed.
- Add or edit articles in `_posts/`. Each WordPress article on this site has a simple Jekyll post file there.
- Update the featured work cards on `_pages/about.md`.

`scripts/import-wordpress-posts.js` can import published WordPress posts from the REST API again. Use an application password only in the terminal command; never place it in this repository or any site file.
